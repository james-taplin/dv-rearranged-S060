TRIAL SCOPE
Two native two-cylinder engines use the accepted shared native traction/RPM/slip
model. The main engine and mass are retained; the rear is an explicit conservative
native-equivalent capacity addition, not a calibrated historical compound model.
Both actual steam demands are charged to the existing boiler.

The existing six native oilcup circuits and refill controls remain functional.
The rear engine shares native lubrication; separate rear refill circuits are not
added. The shared chimney retains the native main pressure response for pulses.
Named cylinder walk/item shells follow the moving frame; the fused native boiler
collision hull is retained. Native detailed frame halves meet at an uncapped
articulation cut. Actual clearance, footing, materials and sound need game viewing.

Realistic Firing's reported overspeed remains unresolved. Current beta
recommendation is to run without Realistic Firing and test native issues
independently; RF-specific compatibility work is out of scope. This build does
not install or change MultiCylinderChuffFix or any other mod. Restart for tests.
