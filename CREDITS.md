# Credits

Rearranged S060 is an MIT-licensed fork of JimTaplin's Rearranged S282 B99 /
Re:Arranged fork, which is based on Peter Schinske's original Rearranged S282.

- **Peter Schinske / SatiricRug** — original Rearranged S282, the wheel-arrangement
  foundation and inherited custom Franklin running gear and pipework.
- **JimTaplin / james-taplin** — Rearranged S282 B99/Re:Arranged fork development and the
  S060 adaptation, arrangements and integration. The Dockside 0.8.1 continuous
  rod/web design and wheel-input presentation adapt the later S282 2.1 Franklin
  work to S060-specific geometry, materials and native crank authoring.
- **discorddraconequus** — Verde compound locomotive and the stage-specific chuff
  and sound-tuning reference adapted for the Meyer. Verde was supplied as a
  compound template with the author's invitation. Its native stage controls,
  LP chimney routing and lower-pressure chuff bands informed the S060 exhaust tuning.
  The author's Verde authoring pack also provided a reference for native effect
  ownership, per-cylinder timing and reverser/motion patterns. These patterns
  were reviewed against the S060's own geometry and native readers; no Verde
  meshes, textures, animation clips or audio are included in these packages.
- **Niko Fox and Insprill** — Derail Valley modding template.
- **Radu, Perfare and aelurum** — AssetStudio.
- **Dummiesman** — Runtime OBJ Importer.
- **newman55 and Unity Mod Manager contributors** — mod installation and loading.
- **Katycat, Wiz, lassombra and Custom Car Loader contributors** — asset loading.
- **Loco Mesh Splitter contributors** — native locomotive mesh access.
- **Altfuture** — Derail Valley and its original locomotive assets, referenced
  from the installed game.
