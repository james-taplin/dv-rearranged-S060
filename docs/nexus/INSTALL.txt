REARRANGED S060 0.3.3 - INSTALLATION AND USE

BEFORE INSTALLATION

1. Close Derail Valley.
2. Install Unity Mod Manager 0.27.3 or later for Derail Valley.
3. Install Loco Mesh Splitter.
4. Install Custom Car Loader and its requirements, including DV Language Helper.

UPDATE AN OLDER INSTALLATION

If UMM lists either separate asset pack below, remove that entry before you install this ZIP.

RS060_Meyer_0440
RS060_Franklin_Dockside_0440

Keep the Rearranged S060 entry and its Settings.xml file.
The new ZIP includes both asset packs. Duplicate packs can prevent correct loading.
If these separate entries are absent, continue with INSTALL THE MOD.

INSTALL THE MOD

1. Open Unity Mod Manager.
2. Select Derail Valley.
3. Open the Mods tab.
4. Drag RearrangedS060-0.3.3-UMM.zip into the Mods tab.
5. Make sure that Rearranged S060 shows version 0.3.3.
6. Make sure that the mod and its requirements are enabled.
7. Start Derail Valley.

Do not extract the ZIP before you use UMM.
The ZIP installs one RearrangedS060 folder. It includes all locomotive parts.

SELECT AN ARRANGEMENT

1. Stop the S060.
2. Close the regulator.
3. Wait until the wheels stop slipping or sliding.
4. If you select or leave Meyer, disconnect the rear coupler.
5. If you select or leave Meyer, disconnect the rear brake hose.
6. If you select or leave Meyer, make sure that the track behind the locomotive is clear.
7. Select WHEEL REARRANGER on the comms radio.
8. Point the radio at the S060.
9. Select the required arrangement.
10. Confirm the selection on the radio.

You can also select an arrangement in the Rearranged S060 menu in UMM.
Use the original S060 locomotive. Do not use the CCL asset entries as separate locomotives.

IF AN ASSET PACK IS NOT AVAILABLE

1. Close Derail Valley.
2. Make sure that Custom Car Loader and its requirements are installed and enabled.
3. Make sure that Loco Mesh Splitter is installed and enabled.
4. Remove duplicate standalone Meyer or Dockside asset entries, if present.
5. Start Derail Valley again.

If the problem remains, include the game version, mod version and Player.log in your report.
Player.log is in this folder:
%USERPROFILE%\AppData\LocalLow\Altfuture\Derail Valley
