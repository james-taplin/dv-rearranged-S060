REARRANGED S060 - PUBLIC BETA 0.22.2

ONE ZIP - DRAG DIRECTLY INTO UNITY MOD MANAGER

This package includes the runtime, both Meyer/Dockside bundles and Shay models.
There are no ZIPs inside this ZIP. UMM installs one RearrangedS060 folder;
Custom Car Loader finds the included bundles in its assets subfolders.

1. Close Derail Valley.
2. Install Unity Mod Manager, Loco Mesh Splitter, Custom Car Loader and CCL's
   own requirements first (including DV Language Helper for CCL 3.1.11).
3. Open UMM, select Derail Valley and open the Mods tab.
4. Drag RearrangedS060-0.22.2-UMM.zip directly into UMM.
5. Check Rearranged S060 is installed and enabled, then launch the game.

UPGRADING AN EARLIER THREE-PART TEST INSTALL - ONE-TIME STEP

Before installing this combined package, use UMM to uninstall ONLY these two
old standalone entries, if present:
  RS060_Meyer_0440 - S060 Meyer with attached pannier steam bogie
  RS060_Franklin_Dockside_0440 - Franklin Dockside 0-4-4-0T prototype

Keep RearrangedS060 itself and its Settings.xml. UMM's normal update retains
its settings. The new package contains the same asset IDs inside one mod;
leaving the old asset packs enabled would make CCL find duplicate IDs. UMM
does not automatically remove separate old mods. New users skip this step.

Required: Derail Valley B99, UMM 0.27.3 or newer, Loco Mesh Splitter and Custom
Car Loader. Rearranged S282 is not required. Dependencies are not bundled.
Runtime 0.22.2 keeps the two-truck Shay to the radio and UMM arrangement chooser.
Both asset bundles stay at 0.7.0; existing saves and settings remain compatible.
Existing single-folder installs update normally through UMM. Older mod versions
cannot restore the new Shay arrangement; this version reads earlier saves.

CHOOSING AN ARRANGEMENT

Use WHEEL REARRANGER on the comms radio and point at a native S060. Arrangement
selection is also available in Rearranged S060's UMM panel. The CCL spawner
entries remain debug asset donors; use the native S060 radio for normal play.

Stop and close the regulator before switching. Before entering or leaving
Meyer, uncouple the rear, disconnect its hose and leave clear track behind.
