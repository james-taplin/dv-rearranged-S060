+ middle (each extra engine the same size as the duplex rear engine).

Two three-axle engines on about 1.07 m drivers. Each engine is a 0.75-scale copy

POWER TEST
1. Open Unity Mod Manager (Ctrl+F10), select Rearranged S282.
2. Click START POWER DIAGNOSTICS. Close the manager and drive normally.
   All actively simulated S282s are captured, including an untouched stock one.
3. Compare stock 2-8-2 with 4-12-2, with Realistic Firing disabled.
   Start a separate capture for each case and note the arrangement/settings.
   Keep Utilities limited to no-derail for this comparison; leave its extra-force
   keys unused. A sustained RPM/slip trace is more useful than a maximum speed.
4. Reopen the manager and click STOP AND SAVE POWER DIAGNOSTICS.
5. Files are in Mods/RearrangedS282/diagnostics/power-<UTC timestamp>.jsonl.
   Send the files or ask Codex to inspect them locally along with the game log.
   Samples flush about once a second and on stop/normal exit. Capture stops after
   30 minutes, 100,000 rows or approximately 64 MiB, whichever comes first.

The 1.4.2 capture also records simulation-update failure status and the originating
exception without suppressing it. This matters because a failed boiler tick can
skip engine torque/phase updates while native physics retains old torque. Record
from before a failure starts; an increasing RPM INPUT alone does not prove the
engine completed its tick. Compare per-engine crankPhase, chuffEvent and torque.
Samples include simUpdateFailed and simUpdateFault (type/message). The 10 Hz
capture samples faults rather than counting every exception or brief failure.
The new reported 0-8-0 run used infinite steam. Use ordinary steam/resources for
native validation. Earlier 400+ km/h reports had different unknowns; those logs
are retained as evidence, not a requirement to repeat RF-specific testing.

The file records car/arrangement, road speed and rolling RPM, live traction-port
wheel RPM, crank RPM, slip/slide, the reconstructed slip target, throttle/cutoff,
torque, force, pressures and steam flow. It records active mod versions too.
Wheel RPM means simulated traction RPM, not a measurement of the rendered wheel.
Normal smoothing and differently timed ECS updates can cause brief differences.

RANDOM ARRANGEMENTS
Open Show arrangement and random-spawn settings, then enable Spawn S282 with
random wheel arrangement. Tick the layouts you want included. All 33 conventional
arrangements are available by default. The two articulated layouts, 4-0-4 and
experimental 2-2-2 are additional opt-in choices; an empty pool falls back to stock 2-8-2.
Only newly spawned S282s roll a choice. Existing locomotives loaded from an old
save remain stock. Previously saved choices keep their identity. Settings save
through Unity Mod Manager's normal settings save/close flow.

SAVE/RELOAD
Use a disposable test save first. Select an arrangement by radio, save, exit and
reload. Check that each locomotive gets its own arrangement back, including a
stock control. Check that a randomly spawned arrangement also stays the same.
Automatic restoration waits for the loco to stop, regulator to close, and force/
slip to settle. A loaded moving locomotive can temporarily appear stock until
those conditions are met. The game log identifies pending/restored selections.
Manual radio selection replaces a pending saved choice.
Removing this mod leaves the native S282 usable with stock running gear.
Older mod builds ignore the new data; resaving with an older build may discard it.
