MOD TITLE
Rearranged S282 - B99 Conventional Arrangements Beta

SHORT SUMMARY
B99 update of SatiricRug's Rearranged S282 by JimTaplin. Choose from 31 conventional
wheel arrangements, with native B99 physics and six oilcup bindings. No duplexes;
arrangement selections are temporary in this beta.

DESCRIPTION
This beta brings the conventional arrangements from SatiricRug's Rearranged S282
to Derail Valley B99. The B99 port is by JimTaplin, with full credit to the original
author and the original license retained.

Choose from 31 arrangements using Wheel Rearranger on the comms radio, including
four-, six-, eight-, ten- and twelve-coupled layouts and the high-speed variants.
The update uses B99's native per-locomotive wheel/traction/slip systems and preserves
the six native oilcup circuits, refill controls and position-sync bindings.

IMPORTANT: this is a conventional-arrangements beta. Duplexes are not included.
Selected arrangements do not persist across reloads, and random spawning is off.
Please use a sandbox save while testing.

Requirements
- Windows version of Derail Valley B99; tested on 99-build2702.
- Unity Mod Manager.
- Locomotive Mesh Splitter; tested with version 1.1.9.
  https://www.nexusmods.com/derailvalley/mods/867
Derailroader and CCL are not required by this mod.

Installation
Close the game, back up your old RearrangedS282 folder, then install this ZIP with
Unity Mod Manager, or extract its RearrangedS282 folder into the game's Mods folder.
Replace the old version rather than keeping a second active copy. Keep the included
AssetStudioModCLI_net472_win64_contained folder: the original mesh exporter prepares
rod meshes locally from your installed game.

Using the mod
Select Wheel Rearranger on the comms radio, select an S282, choose an arrangement
and confirm. The engine must be stopped, railed, with regulator closed and force/
slip settled. Choose 2-8-2 Mikado to restore stock. First use may pause briefly for
mesh preparation. Manual use supports changing multiple S282s independently.

Test status
All 31 stationary structural tests passed in game, covering axle counts, stock
restoration, second-locomotive isolation and preservation of all six oilcup bindings.
This beta uses the exact DLL from that successful run. Initial visual feedback is
positive. More feedback is wanted on motion/rod geometry, loaded pulling, wheelslip,
sanding, audio/particles, oilcup opening/refilling/alignment, LODs and external-control
unload/reload. Repair/explosion and broad mod compatibility remain unverified.

Physics scope
Native S282 mass and engine dimensions are retained. Axle count, driver registration
and wheel radius update per locomotive. Load is currently approximated as equal
weight per physical axle; the arrangements are not calibrated prototype simulations.

Reporting a problem
Please give the arrangement, previous arrangement, locomotive ID, steps to reproduce,
screenshot/video, game/mod versions and other relevant mods. Include Player.log and
UMM Log.txt. If you run the optional structural test in the mod's UMM settings,
include stage2-runtime-checks.json too. The download includes a manual-test checklist.
