DESCRIPTION
This independent B99 fork keeps SatiricRug's original arrangement work and MIT
notices. Requires Windows, Derail Valley B99, Unity Mod Manager 0.27.3 or later and
Locomotive Mesh Splitter 1.1.9: https://www.nexusmods.com/derailvalley/mods/867

Install through UMM with the game closed, replacing any older RearrangedS282 copy,
and keep the included exporter and assets folders. Use Wheel Rearranger on the
comms radio; stop and close the regulator before switching.

Random spawning is off by default. When enabled, it uses the useful conventional
layouts; the high-speed variants, 2-2-2, 4-14-4, 4-0-4 and all articulated layouts
are opt-in.

The in-game structural self-test passed for 40 arrangements. The 0-2-2-2-0,
0-8-8-0 and 2-6-8-0, the bigger triplex drivers, 4-14-4 spacing, grip limits and
curve drag have passed offline checks only so far; please use a test save first.
