SHORT FILE DESCRIPTION
31 conventional S282 arrangements for B99. Adds optional random spawns, saved
per-engine choices, RPM/slip diagnostics, a high-speed rod timing candidate and
optional Delta trailing truck compatibility. New 1.3.6 changes await in-game
confirmation. No duplexes; Realistic Firing overspeed is not fixed.

DESCRIPTION / CHANGELOG
This independent B99 fork retains SatiricRug's original arrangement work and MIT
notices. Requires Windows, Derail Valley B99, Unity Mod Manager 0.27.3 or later,
and Locomotive Mesh Splitter 1.1.9:
https://www.nexusmods.com/derailvalley/mods/867

Since 1.3.3 Beta 1:
- Optional random spawning across all 31 conventional layouts; defaults off.
- Manual and random arrangement choices saved per locomotive. Restores wait until
  stationary with the regulator closed and force/slip settled.
- Opt-in diagnostics for simulated wheel/crank RPM, slip, controls, torque and steam.
- Rod timing candidate: added wheels copy their corresponding fourth wheel's
  completed pose in LateUpdate. Included in this 1.3.6 DLL; visual retest pending.
- Optional Delta compatibility for S282 Model Tweaks 1.1.0 / DV Car Changer 1.5.4,
  preserving the selected arrangement's physical running gear during apply/remove.

Delta graphics display on single-trailing-axle layouts (x-x-2). On x-x-0/x-x-4,
the Delta choice stays saved but its graphics are hidden. Optional mods and their
dependencies must be installed separately; no Delta meshes are included.

Install through UMM with the game closed, replacing the older RearrangedS282 copy.
Keep the included exporter folder. Use Wheel Rearranger on the comms radio; stop
and close the regulator before switching. Restart to update or unload the mod.

B99's six native oiling circuits are retained. No duplexes, multiplayer sync,
custom steam-power boost or speed cap are added.

TEST STATUS / KNOWN ISSUE
Native-reference build and offline checks pass. The previous 31-arrangement
in-game structural pass belongs to 1.3.3. There is no 1.3.6 in-game structural,
rod/Delta visual, save/reload, deletion or pooled-reuse validation yet; use a
disposable sandbox first. Exact checks and limits are included in TEST_STATUS.txt.

Reported extreme speed with Realistic Firing's cylinder model remains under
investigation. The reporter found switching that feature off stopped the issue;
this release does not contain a confirmed power fix. Diagnostic captures with
cylinders off/on are useful for further investigation.

For reports, include arrangements, reproduction steps, game/mod versions and
Player.log, plus diagnostic JSONL or structural JSON if captured.
